# coreutils

The `coreutils` package: `DIR`, `TYPE`, `MORE`, `COPY`, `MOVE`, `REN`, `DEL`, `MD`, `RD`, `EDIT`, `WRITE`, `CLS`, `COLOR`, `VER`, `BEEP`, `SPEED`, `EJECT`, `SHUTDOWN`, `RESTART`, `IPCONFIG`, `PING`, `DRIVERS` and `HELP`. Each command is one `.c` file. Every DOS-XC installation has it.

Build it alone with `coreutils/package.sh [32] [64]`.

# Vim for DOS-XC

Builds Vim 9.1.1000 as the `Vim` package (`VIM`, and `VI`, `VIEW`, `EX` and `VIMDIFF` as batch files).

- `build.sh [x86_64|i686]` compiles it into `build/ports`.
- `package.sh [32] [64]` packs that as a `.dsp`.

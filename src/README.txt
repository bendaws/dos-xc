/batch - Batch command processor
/boot - Bootloader with BIOS/UEFI
/coreutils - Core DOS commands
/desktop - DOS-XC Desktop Environment
/dos - Original 16-bit DOS runtime
/drivers - System drivers for fs, KB, mouse, and speakers
/kernel - DOS-XC kernel
/libc - C library for DOS-XC
/netdrivers - Network drivers included with the system
/pkg - Package manager
/programs - Ultra-core programs (the shell driver). Formerly home of coreutils
/runtime - Modern 32-bit/64-bit program runtime
/setup - Terminal setup program
/shell - DOS shell
/vdm - New 16-bit emulator for old DOS-programs

# ethernet

The `ethernet` package: drivers for Intel PRO/1000 (`E1000.DRV`), Broadcom NetXtreme (`TG3.DRV`) and virtio-net (`VIRTIONET.DRV`). See [docs/NETWORK.md](../docs/NETWORK.md) and [docs/DRIVERS.md](../docs/DRIVERS.md).

Build it alone with `ethernet/package.sh [32] [64]`.

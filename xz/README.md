# XZ Utils for DOS-XC

Builds XZ Utils 5.8.1 as the `xz` package (`XZ`, `UNXZ`, `XZCAT`).

- `build.sh [x86_64|i686]` compiles it into `build/ports`.
- `package.sh [32] [64]` packs that as a `.dsp`.
